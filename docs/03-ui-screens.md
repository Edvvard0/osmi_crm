## 1. Принципы дизайна

**Строгий инструмент, а не витрина.** Интерфейс работает на скорость: менеджер принимает машину за минуту, механик управляет работой одной рукой, руководитель за 10 секунд понимает, как идут дела во всех точках.

1. **Минимум цвета.** Интерфейс монохромный (графит и белый). Цвет появляется только там, где несёт смысл: статус, ошибка, главное действие.
2. **Одно главное действие на экране.** Одна основная кнопка, остальные — вторичные или в меню.
3. **Данные важнее оформления.** Никаких декоративных иллюстраций, градиентов и теней. Разделение блоков — тонкими линиями и отступами.
4. **Плотность по роли.** Механику — крупно и просторно. Менеджеру и руководителю — плотные таблицы, больше данных на экране.
5. **Предсказуемость.** Одинаковые действия выглядят и расположены одинаково на всех экранах.
6. **Ничего не теряется.** Несохранённые формы предупреждают при уходе, опасные действия требуют подтверждения, ошибки объясняют, что сделать.

## 2. Дизайн-система

### 2.1 Цвета

| Токен | Светлая тема | Тёмная тема | Применение |
|---|---|---|---|
| `bg` | `#FFFFFF` | `#0E0E10` | Фон страницы |
| `surface` | `#F6F6F7` | `#17171A` | Панели, сайдбар, шапка таблицы |
| `border` | `#E4E4E7` | `#2A2A2E` | Линии, рамки полей |
| `text` | `#18181B` | `#F4F4F5` | Основной текст |
| `text-muted` | `#71717A` | `#A1A1AA` | Подписи, второстепенное |
| `accent` | `#1F3A8A` | `#6E8EF5` | Главная кнопка, активный пункт меню, ссылки |
| `danger` | `#B42318` | `#F97066` | Ошибки, удаление, просрочка |

**Статусы** — приглушённые цвета, только в бейджах (точка + текст), не заливкой больших областей:

| Цвет | Статусы |
|---|---|
| Серый | Новый, запланирована, ожидает |
| Синий | Диагностика, в работе |
| Янтарный | Ждёт согласования, ждёт запчасти, пауза |
| Фиолетовый | Проверка качества |
| Зелёный | Готов, оплачен, выполнено |
| Красный | Просрочен, отменён, не приехал |

**Отделы** обозначаются текстовой меткой `СЕРВИС` / `ДЕТЕЙЛИНГ` моноширинным капсом в рамке, без цвета. Так отдел виден везде и не спорит со статусами.

Тёмная тема — по системной настройке с ручным переключателем в «Настройках» (C-02). Механикам в боксах тёмная тема удобнее при ярком свете ламп.

### 2.2 Типографика

- Шрифт: **Inter** (fallback: системный sans-serif). Цифры — `font-variant-numeric: tabular-nums`, чтобы суммы в столбцах выравнивались.
- Госномера, VIN, номера заказов — **JetBrains Mono**.

| Стиль | Размер / межстрочный | Начертание | Где |
|---|---|---|---|
| Display | 32 / 40 | 600 | KPI-цифры на дашборде |
| H1 | 24 / 32 | 600 | Заголовок страницы |
| H2 | 18 / 28 | 600 | Заголовки блоков |
| Body | 14 / 20 | 400 | Основной текст, таблицы (desktop) |
| Body-L | 16 / 24 | 400 | Основной текст на мобильном, экраны механика |
| Caption | 12 / 16 | 500 | Подписи, бейджи, заголовки колонок (капс, разрядка 0.04em) |

### 2.3 Сетка и формы

- Шаг сетки 4 px, основные отступы 8 / 12 / 16 / 24 / 32.
- Скругление 6 px (поля, кнопки, карточки), бейджи — 4 px.
- Тени не используются, кроме выпадающих меню и диалогов (одна мягкая тень).
- Иконки Lucide, обводка 1.5 px, размер 16 (desktop) и 20–24 (mobile).

### 2.4 Компоненты

| Компонент | Правила |
|---|---|
| Кнопки | Primary (заливка `accent`), Secondary (рамка), Ghost (только текст), Danger. Высота 36 px desktop, 44 px mobile, 56 px на экранах механика |
| Поля ввода | Подпись над полем, подсказка под полем, ошибка красным под полем. Маски: телефон `+7 (999) 123-45-67`, госномер, VIN |
| Поиск с выбором (combobox) | Клиент, авто, услуга, запчасть. Поиск с первого символа, создание нового прямо из списка |
| Таблица | Липкая шапка, сортировка по клику, строка 40 px, выбор колонок, пагинация или бесконечная прокрутка. На mobile — карточки |
| Бейдж статуса | Цветная точка 6 px + текст |
| Боковая панель (drawer) | Быстрое создание и редактирование без ухода со страницы. На mobile — bottom sheet на весь экран |
| Диалог подтверждения | Для удаления, отмены, возврата. Кнопка повторяет действие: «Отменить заказ», а не «ОК» |
| Toast | Внизу справа (desktop), сверху (mobile). Успех исчезает через 4 с, ошибка висит до закрытия |
| Пустое состояние | Одна строка текста и кнопка действия, без иллюстраций |
| Скелетоны | Вместо спиннеров при загрузке списков |

### 2.5 Форматы данных

| Данные | Формат |
|---|---|
| Дата | `09.11.2026`, в списках — «сегодня», «вчера» |
| Время | `14:30`, 24-часовой формат, часовой пояс точки |
| Деньги | `12 500 ₽`, копейки только если они не нулевые |
| Телефон | `+7 (999) 123-45-67`, по клику — звонок (на mobile) |
| Госномер | `А 123 ВС 77` моноширинным |
| Длительность | `1 ч 25 мин` |

### 2.6 Адаптивность

| Диапазон | Навигация | Особенности |
|---|---|---|
| < 640 px (телефон) | Нижняя панель на 4–5 пунктов + «Ещё» | Карточки вместо таблиц, формы на весь экран, липкая панель действий внизу |
| 640–1023 px (планшет) | Свёрнутый сайдбар (иконки, 64 px) | Таблицы с меньшим набором колонок, drawer на 480 px |
| ≥ 1024 px (desktop) | Сайдбар 240 px, сворачивается | Таблицы полностью, карточка заказа в две колонки |
| ≥ 1440 px | То же | Контент ограничен 1600 px, на дашборде больше графиков в ряд |

Все кликабельные элементы на сенсорных экранах — не меньше 44 × 44 px.

### 2.8 Доступность
- Контраст не ниже WCAG AA (4.5:1 для текста).
- Видимый фокус, работа с клавиатуры (`Tab`, `Enter`, `Esc`), горячие клавиши для частых действий менеджера (`N` — новый заказ, `Ctrl+K` — поиск).
- У всех полей есть подписи, у иконок-кнопок — `aria-label`.
- Статус никогда не передаётся только цветом: всегда есть текст.

### 2.9 Тепловая карта активности

Показывает, в какие дни сотрудник работал. Используется в D-05 (вкладка «Активность»), MG-17 и M-07.

```
Активность · 2026                                   [2026 ▾]
      ноя   дек   янв   фев   мар   апр   май   июн   июл ...
Пн    ▪ ▪ ■ ▪ ▫ ■ ■ ▪ ▪ ■ ■ ■ ▪ ▫ ▪ ■ ...
Ср    ■ ■ ■ ▪ ▫ ■ █ ■ ▪ ■ █ ■ ■ ▫ ■ ■ ...
Пт    ■ █ ■ ■ ▫ ■ █ ■ ■ █ █ ■ ■ ▫ ■ █ ...
                                        Меньше ▫ ▪ ■ ▓ █ Больше
Рабочих дней 214 · Часов 1 486 · В среднем 6,9 ч · Самая длинная серия 12 дней
```

| Свойство | Решение |
|---|---|
| Сетка | Столбцы — недели, строки — дни недели (Пн–Вс), подписаны Пн, Ср, Пт. Над сеткой — названия месяцев. Ячейка 12 × 12 px, зазор 3 px, радиус 2 px |
| Цвет | 5 уровней: 0 — `surface-2` (нет активности), 1–4 — оттенки `accent` с нарастающей насыщенностью. Отдельные палитры для светлой и тёмной темы, контраст соседних уровней проверен. Других цветов на карте нет |
| Уровни | Механик: нет работы / до 2 ч / 2–5 ч / 5–8 ч / больше 8 ч. Менеджер: по числу действий за день. Пороги задаются в D-09 |
| Подсказка | По наведению (desktop) или касанию (mobile): «Вторник, 14 октября 2026 · 7 ч 20 мин · 3 работы». Выходной без работы — «Нет активности» |
| Клик по дню | Открывает под картой список работ за день: заказ (ссылка), госномер, работа, интервалы времени |
| Будущие дни | Не отображаются; дни до приёма сотрудника — пустые без рамки |
| Desktop | 12 месяцев в одну строку, выбор года или «последние 12 месяцев» |
| Mobile | По умолчанию последние 3 месяца, ячейки 16 × 16 px (удобно касаться), горизонтальная прокрутка к более ранним месяцам, итоги — карточками под картой |
| Загрузка | Скелетон сетки того же размера, без смещения контента |
| Доступность | У каждой ячейки `aria-label` с датой и значением, переход по ячейкам стрелками. Рядом — переключатель «Таблица», показывающий те же данные списком |

### 2.10 Ошибки и пустые состояния

Пользователь видит только понятный текст на русском и действие, которое можно сделать. Трейсбеки, коды SQL, имена полей БД, технические сообщения браузера и тексты ошибок сервера на экран не попадают.

| Ситуация | Что видит пользователь |
|---|---|
| Ошибка в поле формы | Красный текст под полем: «Введите номер в формате А 123 ВС 77». Форма не очищается, фокус на первое поле с ошибкой |
| Конфликт данных (два менеджера) | Диалог «Заказ изменил другой сотрудник. Обновите страницу, чтобы увидеть изменения» и кнопка «Обновить» |
| Нет прав | Toast «Недостаточно прав для этого действия» или экран C-03 |
| Нет сети | Баннер C-04, кнопка «Повторить» |
| Сессия истекла | Экран входа с сообщением «Сессия истекла, войдите снова»; после входа — возврат на ту же страницу |
| Слишком много попыток | «Слишком много попыток. Повторите через 2 минуты» |
| Ошибка сервера | Toast «Что-то пошло не так. Попробуйте ещё раз · код 7f3a9c» с кнопкой «Копировать код» |
| Сломался экран | C-06 вместо экрана, меню остаётся рабочим |
| Пустой список | Короткая строка и главное действие: «Клиентов пока нет · [+ Новый клиент]» |

Код обращения — первые 6 символов `request_id`. По нему руководитель или разработчик находит полную ошибку в логах сервера.

## 3. Общие экраны (все роли)

| Код | Экран | Содержание |
|---|---|---|
| C-01 | **Вход** | По центру: название системы, поля «Логин» и «Пароль» (показать/скрыть), кнопка «Войти». Без регистрации и «Забыли пароль» — пароль сбрасывает руководитель (подсказка мелким текстом). Ошибка — одной строкой над кнопкой |
| C-02 | **Настройки** (профиль) | Открывается из меню «Профиль ▾» в шапке (пункты «Настройки» и «Выйти») на desktop, из пункта «Настройки» нижней панели у механика и из «Ещё → Настройки» у менеджера и руководителя на mobile. Секции: **Профиль** — ФИО, роль, точки (только просмотр). **Безопасность** — «Сменить пароль»: текущий пароль, новый, повтор, индикатор требований (длина, не совпадает с логином); после смены toast «Пароль изменён», другие устройства выходят из системы; ниже — активные сессии с кнопкой «Завершить». **Telegram** — статус, «Подключить» (код, ссылка, QR-код), «Отключить», переключатели типов уведомлений. **Внешний вид** — тема: системная / светлая / тёмная. Смена пароля доступна только здесь: после входа система ничего не требует и сразу открывает рабочий стол роли |
| C-03 | **Нет доступа / не найдено** | Одна строка и кнопка «На главную» |
| C-04 | **Офлайн** | Баннер сверху «Нет соединения. Показаны данные на 14:32». Кнопки изменения неактивны с подсказкой |
| C-05 | **Обновление приложения** | Toast «Доступна новая версия» с кнопкой «Обновить» |
| C-06 | **Что-то пошло не так** | Показывается вместо упавшего экрана, меню и шапка остаются рабочими. Иконка, заголовок «Не удалось отобразить страницу», строка «Попробуйте обновить. Если не поможет — сообщите код руководителю», код обращения моноширинным шрифтом с кнопкой «Копировать», кнопки «Обновить» и «На главную». Никаких технических деталей |

## 4. Механик

**Устройство:** телефон, иногда планшет на стойке в боксе.
**Стиль:** крупный шрифт (Body-L), кнопки 56 px, высокий контраст, минимум ввода текста. Основные действия — в липкой панели внизу, под большой палец. Цены и контакты клиента не показываются.

**Навигация (нижняя панель):** Задачи · Заявки · Заработок · Настройки

| Код | Экран | Содержание |
|---|---|---|
| M-01 | **Мои задачи** | Сверху — карточка активной работы с живым таймером и кнопкой «Пауза». Ниже — переключатель «Сегодня / Все открытые» и список карточек: госномер крупно, марка и модель, название работы, норматив, статус, метка отдела. Сортировка: в работе → на паузе → ожидают. Обновление жестом вниз |
| M-02 | **Карточка работы** | Шапка: госномер, авто, пробег, номер заказа. Блоки: «Жалоба клиента», «Состояние при приёме» (текст менеджера), «Мои работы в этом заказе» (каждая со статусом), «Комментарии». Липкая панель: «Начать» / «Пауза» + «Завершить». Вторичные действия в меню «⋯»: «Нужна запчасть», «Рекомендация», «Комментарий» |
| M-03 | **Завершение работы** | Bottom sheet: фактическое время (из таймера), поле комментария (необязательно), кнопка «Завершить работу» |
| M-04 | **Заявка на запчасть** | Поиск по справочнику или свободный текст, количество (крупные кнопки − / +), комментарий, «Отправить» |
| M-05 | **Мои заявки** | Список со статусами: новая, одобрена, отклонена (с причиной), выдана |
| M-06 | **Рекомендация** | Текст, приоритет (низкий / средний / высокий). Привязывается к авто — менеджер увидит при следующем визите |
| M-07 | **Мой заработок** | Период (текущий месяц по умолчанию). Крупно — начислено. Ниже: выполнено работ, нормочасы план / факт, премии и удержания. Блок «Мои рабочие дни» — тепловая карта за последние 3 месяца (раздел 2.9) с итогами: рабочих дней, часов. Список выполненных работ по дням |

## 5. Менеджер

**Устройство:** ПК на ресепшене, планшет при приёмке машины, телефон для проверки статусов.
**Стиль:** плотные таблицы, быстрые формы в боковой панели, горячие клавиши, глобальный поиск. Работает в рамках своих точек, точку переключает в шапке.

**Навигация (сайдбар):** Сегодня · Календарь · Заказ-наряды · Клиенты · Склад · Касса · Каталог · Отчёт точки
**Mobile (нижняя панель):** Сегодня · Заказы · Календарь · Поиск · Ещё

| Код | Экран | Содержание |
|---|---|---|
| MG-01 | **Сегодня** | Рабочий стол точки. Строка счётчиков: в работе, ждут запчасти, готовы к выдаче, просрочены. Лента записей на сегодня по времени со статусами (кнопки «Приехал» → «Создать заказ»). Загрузка постов полосками. Блок «Требует внимания»: заявки механиков, просрочки, дефицит на складе |
| MG-02 | **Календарь** | Колонки — посты, строки — время с шагом 15 минут, линия текущего времени. Карточка записи: время, госномер, услуги, цвет статуса полоской слева. Создание по клику на слот, перенос перетаскиванием, растягивание по длительности. Режимы «День / Неделя», фильтр «Сервис / Детейлинг». Mobile: список по дню, переключение постов вкладками |

## 6. Руководитель

**Устройство:** ПК для анализа, телефон для быстрого взгляда на показатели.
**Стиль:** аналитический. KPI крупными цифрами с изменением к прошлому периоду, графики линиями и столбцами в монохроме с одним акцентом, сравнительные таблицы точек. Переключатель «Все точки / конкретная точка» и период — на каждом аналитическом экране. Имеет доступ ко всем экранам менеджера по любой точке.

**Навигация (сайдбар):** Обзор · Отчёты · Зарплата · *[разделитель]* · Заказ-наряды · Календарь · Клиенты · Склад · Касса · *[разделитель]* · Сотрудники · Точки · Каталог и цены · Журнал действий · Системные настройки
**Mobile (нижняя панель):** Обзор · Отчёты · Заказы · Сотрудники · Ещё

| Код | Экран | Содержание |
|---|---|---|
| D-01 | **Обзор** | Фильтры: точка, период (сегодня / неделя / месяц / свой). KPI-плитки: выручка, заказов, средний чек, загрузка постов, доля детейлинга, конверсия «запись → визит» — каждая с изменением к прошлому периоду (▲ / ▼). График выручки по дням (линия на точку или сервис / детейлинг). Таблица сравнения точек. Топ-10 услуг. Блок «Внимание»: возвраты, крупные скидки, просрочки, дефицит |
| D-02 | **Отчёты** | Список отчётов слева, параметры сверху, результат таблицей с графиком. Отчёты: выручка по точкам и отделам, по услугам, по механикам (норма / факт / выработка %), клиенты (новые / повторные, отток), склад (оборот, маржа), расходы, прибыль (выручка − себестоимость запчастей − зарплата − расходы). Экспорт XLSX / CSV |
| D-03 | **Зарплата** | Период (месяц). Таблица сотрудников: схема, выполнено работ, нормочасы, начислено, корректировки, итого. Раскрытие строки — детализация по заказам. Кнопки «Премия / удержание», экспорт ведомости |
| D-04 | **Сотрудники** | Таблица: ФИО, логин, роль, точки, Telegram подключён, последний вход, статус. Фильтр по роли и точке |
| D-05 | **Карточка сотрудника** | Данные, роль, точки (мультивыбор), схема оплаты с историей. Вкладка **«Активность»** — тепловая карта рабочих дней за 12 месяцев (раздел 2.9), выбор года, итоги: рабочих дней, часов всего, в среднем за рабочий день, самая длинная серия; клик по дню — список работ за день. Для механика — часы работы по таймеру, для менеджера — число действий в системе. Действия: «Задать новый пароль» (показывается один раз; сменить его сотрудник может сам в «Настройках», но не обязан), «Заблокировать», «Завершить все сессии» |
| D-06 | **Точки** | Список точек со сводкой. Карточка точки: адрес, код, часовой пояс, часы работы, посты (добавление и порядок), Telegram-чат точки, сотрудники точки |
| D-07 | **Каталог и цены** | Дерево категорий по отделам, таблица услуг. Вкладка «Цены по точкам» — матрица «услуга × точка» с редактированием в ячейке; переопределённые цены выделены жирным. Справочник запчастей |
| D-08 | **Журнал действий** | Лента событий: время, сотрудник, действие, объект (ссылка), точка. Фильтры. Раскрытие — изменения «было → стало» |
| D-09 | **Системные настройки** | Категории расходов, порог скидки для уведомления, время ежедневной сводки, срок хранения сессий, пороги уровней тепловой карты. Свой пароль руководитель меняет в C-02, как и все |
